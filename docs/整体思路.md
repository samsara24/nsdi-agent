# RCA v2 整体思路与实现对齐

本文保留原始框架思路，并补充当前实现状态。目标系统不是强制三分类器，而是“历史证据图匹配 + 物理约束 + SOP/LLM 推理 + 低置信度降级 + 人工确认回灌”的选择性 RCA 流程。

## 端到端链路

1. **N1 证据构建与标准化**：输入一个告警 case，构造 `EvidencePack`，结构性剥离 `label`，记录 observed / missing / not_applicable / invalid 字段状态。
2. **N2 可检视特征抽取**：把遥测转成带物理含义的稀疏 token。`feature-dictionary-v2` 面向 `rca_v2_l2fixed`，显式加入 lane_direction、telemetry_gap 和 serdes_state。
3. **N3 证据图历史匹配**：全局图保存 case-vector，用 IDF 加权 Jaccard 做 Top-N；v2 另有 per-case 诊断子图，记录 FeatureToken、ConstraintCheck、SOPStep 和 Outcome。
4. **N4 分流路由**：路由阈值必须按当前数据集 train-LOO 重新标定，不沿用旧 70%。
5. **N5a 完全匹配**：复用历史纯净 signature 的证据链，但混合桶必须降级或仲裁。
6. **N5b 部分匹配**：根据缺失/冲突证据判断是否补采，必要时用 learned SOP 或 LLM 仲裁。
7. **N5c 低匹配/冷启动**：先执行确定性物理排除，再把 `learned-sop-v1` 的训练归纳路径作为统计先验交给受约束 LLM；SOP 不能冒充当前 case 的物理证据，LLM 每一步仍只能引用当前 evidence token 与约束 ID。
8. **N6 置信度与降级**：综合历史覆盖、SOP 叶子支持、约束合规、证据完整度和推导缺口，输出 final / request_evidence / human_review。
9. **N7 报告生成**：正式实验生成总览 HTML 与逐 case HTML，包含真值/预测、路由、历史候选、SOP 路径、物理证据链、M9 降级原因、LLM 每轮 prompt/原始输出/违规记录和诊断子图。
10. **N8 证据图回灌**：只有人工确认后的 case 可以回灌，自动推理结果只作为 artifact 保存。

## 非自进化正式实验

`scripts/run_offline_sop_llm_experiment.py` 是当前正式入口，固定执行：

1. 只读取 manifest train split，拟合阈值、FeatureModel、161 条稀疏历史向量、EvidenceGraph、learned SOP、train-LOO 分支与 LLM 标定。
2. LLM 参与训练 case 的约束推理，合规推理链写入 evidence-graph-v2 诊断子图；数据集标签作为训练历史的确认标签保存。
3. 把全部训练知识写入 `knowledge/knowledge_bundle.json`，用内容 hash 校验后从磁盘重新加载。
4. test split 只使用冻结参数做特征抽取、检索、SOP+LLM 推理与 M9 决策；测试标签只在推理结束后计算指标。
5. 运行前用 `nvidia-smi` 检查 GPU；无 GPU 不启动正式实验。结束时显式关闭 vLLM、清空 CUDA cache，并保存运行前后 GPU 快照。
6. 输出 `summary.json`、`run_manifest.json`、`outcomes.json`、`traces.json`、训练知识产物及 `html/index.html` + 逐 case 页面。

本轮明确不执行 N8 自动反馈或任何自进化：测试 badcase 不能反向修改知识包、SOP、约束、阈值或向量。

## 当前实验边界

- 已实现：EvidencePack、v2 manifest、feature-dictionary-v2、constraint-library-v3、learned-sop-v1、训练知识包持久化、case-token 图、训练 LLM 诊断子图、测试侧只读加载、SOP+LLM 编排、GPU 生命周期记录和逐 case HTML 报告。
- 仍需实验确认：l2fixed 上的实际 SOP+LLM 指标、路由阈值、learned SOP 深度/剪枝、Top-N、置信度曲线、多 seed 和 fiber 分层稳定性。
- 仍需外部确认：两端 lane 编号是否物理对应、`serdes_snr` 量纲、blackout 时哨兵值语义、专家 SOP 原文。

## 关键边界

物理约束用于禁止不可能或不可信的推理；SOP 是检查顺序和决策树；证据图既保存历史 case-vector，也保存每个 case 的推理链路。`learned-sop-v1` 可以作为数据驱动候选流程，但必须报告支持数和 Wilson 下界，不能冒充专家确认规则。
