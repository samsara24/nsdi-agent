  • M9 将 32 个降级前候选全部拦截；自动最终覆盖率为 0。这说明当前 train-LOO 置信标定没有任何分组同时达到决策阈值与最小支持数，本轮结果不能作为无人值守诊断系统上线。
  • 训练集归纳 SOP 单独命中 67/107（62.62%），高于分支候选的 20/32（62.50%）。当前 LLM 仲裁没有把统计先验稳定转化为更高质量的物理结论。
  • SOP 对类别 L1、fiber 的命中为 0；总体准确率受多数类主导，不能把该总体数值解释为三类均有效。
  • 冷启动 N5c 形成 3 个候选，仅 3 个正确；它是当前主要质量瓶颈，不能用放宽 M7 校验来掩盖。
