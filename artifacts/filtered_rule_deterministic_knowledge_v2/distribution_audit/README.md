# Filtered-rule train/test 分布审计

本报告不调用 LLM。特征、图匹配和路由冻结后，测试标签才用于离线统计。

## test_all_data

- 测试 case：417；同来源训练参考：88。
- 训练标签分布：`{'L1': 38, 'L2': 42, 'fiber': 8}`；测试标签分布：`{'L1': 144, 'L2': 258, 'fiber': 15}`。
- 双相似度精确匹配：33/417；路由：`{'N5a': 33, 'N5b': 133, 'N5c': 251}`。
- S_feature 中位数 0.664，S_graph 中位数 0.721。
- 最近历史标签直接复用准确率：51.80%。
- 训练未见 token：10 种；零双重叠 case：0。

## test_rule1_channel_not_4

- 测试 case：67；同来源训练参考：36。
- 训练标签分布：`{'L1': 12, 'L2': 21, 'fiber': 3}`；测试标签分布：`{'L1': 37, 'L2': 29, 'fiber': 1}`。
- 双相似度精确匹配：3/67；路由：`{'N5a': 3, 'N5b': 8, 'N5c': 56}`。
- S_feature 中位数 0.500，S_graph 中位数 0.635。
- 最近历史标签直接复用准确率：46.27%。
- 训练未见 token：19 种；零双重叠 case：0。

## 结论

- 两个测试集都不是完全脱离训练图，但精确历史模式覆盖很低，不能把近邻标签当最终结论。
- `rule1_channel_not_4` 存在显著时间 schema 漂移：测试侧 SerDes 系统性缺失。缺测 token 应降低证据完整度，不能投根因票。
- 两个来源均存在标签先验漂移；统一训练池可以共享物理证据，但最终阈值和报告必须按来源分层。
- N5c 占比高是数据分布事实。LLM 应基于当前物理证据独立判断，历史与 learned SOP 只能作为低权重上下文。
